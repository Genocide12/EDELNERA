# EDELNERA v0.4.0

- Added 1,398 imported assortment entries (386 women's, 1,012 men's) and a formatted source workbook.
- Changed admin size editing to proposed checkbox choices. Added multi-image product uploads in Admin Studio (up to six photos), local compression, preview, and removal.
- Added enlarged, navigable product photo galleries from catalogue cards and product detail photos.
- Added catalogue and admin inventory pagination for responsive handling of the full assortment.
- Fixed product editor submit handling where its SKU field shadowed the form identifier and prevented saves.
- Added visual browser coverage and real screenshots for the storefront, enlarged gallery, and multiple-photo admin editor.

This remains a static demo: admin changes and uploaded product media stay in the current browser; prices and inventory need verification before commercial use.
