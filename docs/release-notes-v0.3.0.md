# EDELNERA v0.3.0 — The Atelier 2027 Experience

A substantial redesign of the fashion-store concept with a functioning local Admin Studio and a full interactive customer flow.

## Highlights
- A premium editorial storefront in Atelier, Noir and light Malachite design directions
- Responsive desktop/iPhone navigation, hero, collections, sorting and catalogue search
- Product cards respond to cursor hover or screen tap using a cinematic motion effect
- Optional real MP4/WebM hero and item video fields, configurable in Admin Studio
- Product details, selectable sizes, wishlist, cart, inventory checks and discount promo codes
- No-payment demo checkout with local order history and order statuses
- Face portrait (kept in tab memory), body measurements, and manual face-over-outfit visual preview
- Admin Studio: catalogue CRUD, stock/prices/media, orders, promo codes, site content, import/export JSON
- README documentation and automated browser-based visual previews

## Demo limitations

This release is **not** a production shop or a real AI try-on. There is no authenticated administration, shared database, actual fulfilment or payment provider. Face repositioning uses a manually adjusted photo overlay; CSS image motion is not a video of a walking person. A real fashion video can be loaded by supplying an eligible licensed MP4/WebM URL. Admin edits are local to the current browser.
