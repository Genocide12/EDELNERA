# EDELNERA v0.5.0

- Redesigned the storefront in a dark premium editorial style based on the provided EDELNERA mockups while preserving catalogue, checkout, profile and demo-admin features.
- Added main-photo selection and drag-and-drop ordering to product image uploads, with touch-friendly up/down controls.
- Made all saved product photos visible immediately as thumbnails on the catalogue card; shoppers can change the featured photo and open the full gallery.
- Reformatted the women's and men's inventory workbook with actual stock quantities in separate size columns. Undimensioned stock remains in a separate column.
- Extended desktop and iPhone browser tests for the media workflow; smoke and visual test suites pass.

The admin panel, uploads and orders remain browser-local demo data. This release does not add shared hosting, authentication, real payments, or AI try-on.
