# EDELNERA v0.2.0 — Kinetic Catalogue

Released: 2026-11-13

## New
- Animated product photography: hover to play on desktop, tap to play on iPhone and touchscreens.
- Cinematic image pan, scale, tilt, shimmer, and progress indicator.
- Three visual directions: Atelier, Noir and Malachite.
- Private client-side profile with measurement inputs and session-only portrait preview.
- Clear explanations for demo-only AI styling functionality.

## Changes
- Removed the standalone “About the brand” page and associated navigation and promotional links.
- Replaced the brand-story promo with an interactive styling call-to-action.
- Added presentation-quality README with product imagery, architecture visual and transparent feature descriptions.

## Known limitations
- No actual model video, AI body simulation or face replacement.
- No checkout, production backend, real-order workflow or authenticated admin portal.
- Photos and item data are illustrative.
- GitHub Pages publishing may need to be enabled in repository settings.
