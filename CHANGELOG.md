# Changelog

All notable changes to EDELNERA are tracked here.

## [v0.2.0] — 2026-11-13

### Added
- Kinetic product photography with hover and touch interactions
- Local style profile, measurement inputs and demo outfit viewer
- Three switchable design themes
- Illustrated project README and architecture diagram
- Automatic release workflow that checks the `VERSION` file

### Changed
- Removed the standalone brand-story page and related links
- Updated catalogue cards with explicit animation affordance
- Clarified unsupported production features

### Known limitations
The product images are static photographs animated with CSS. No actual fashion video, face replacement, physical garment simulation, live checkout or protected admin backend is present.

Full release notes: [docs/release-notes-v0.2.0.md](docs/release-notes-v0.2.0.md).

## [v0.1.0] — 2026-11-13

Initial standalone HTML/CSS/JavaScript boutique demo: home, catalogue, categories, product details, cart, brand concept, local editor and project information.
